常见问题

SiteNote 是免费的吗？
v1 完全免费。AI 功能需要你提供自己的 OpenAI API Key（你在 OpenAI 那边付费），App 本身不收订阅、不卖数据、不发广告。
没有 OpenAI Key 能用吗？
完全可以。录音、转文字、提醒、PDF 导出全部不需要 OpenAI。AI 是加成，不是必需。也可启用 Apple Intelligence 用本地模型替代。
数据会上传到你们的服务器吗？
不会。SiteNote 没有自己的服务器。只有当你主动开启 OpenAI 集成时，转写文本会发送到 OpenAI（你自己的账户）。详见隐私政策。
支持哪些 iPhone / iOS 版本？
iOS 17 及以上。iPhone 11 及更新机型推荐（A13 芯片以上跑 AI 顺畅）。iPhone 17 Pro Max 体验最佳。
怎么导出 PDF？
日志 tab → 选某一天 → 底部"生成今日简报"按钮。PDF 自动包含人员清单、机械、工程量、照片缩略图，可直接 AirDrop 给业主或邮件发出。
怎么备份数据？
设置 → 报告与导出 → "导出全部数据为 ZIP"。zip 包含速记数据库、录音、照片、设置。建议清空数据前先导一份。
换手机怎么办？
v1 暂不支持自动 iCloud 同步。可以用上一条的 ZIP 备份手动迁移：导出 → 邮件给自己 → 新手机装 App → 导入（v1.1 上线）。多设备实时同步是 v2 计划。
我能加入 Beta 测试吗？
v1 上架前最后一周会开放 TestFlight 外部测试。发邮件说明你的工程角色（PM / 工程师 / 工头）和工地类型，我会发邀请链接。
隐患提醒为什么响这么多次？
这是设计。隐患不及时处理可能死人。SiteNote 普通速记 7 天内每天早上响一次，"隐患"标记的速记 10 天内每天早晚双响。完成或撤销后立即停止。如果太烦，请认真处理那条隐患。
AI 误判了把我的提醒变成日志怎么办？
不会发生。AI 抽取出 LogEntry 后只显示"建议"banner，必须你点"标为施工日志"才会改 deadline 取消提醒。点"保留提醒"就当 AI 没说过。这是产品红线，不可绕过。

  3. App Store 评论 — 公开反馈，会影响评分（但开发者无法在 App Store 直接回复）
  4. TestFlight 反馈（仅限测试用户）— 截图自动附带
